# 画面仕様

## `/`

### 未ログイン

- メールアドレス入力
- Magic Link 送信

### 初回登録

- 表示名入力
- ロール選択
- 親の場合
  - 世帯名入力
- 子の場合
  - 招待コード入力

### ログイン済みダッシュボード

- 自分のプロフィール
- 所属世帯の基本情報
- 親の場合
  - 子ども一覧への導線
  - 招待コード表示
  - 今月の未承認ルール件数
- 子の場合
  - 自分に関するルール画面への導線
  - 自分に関するポイント画面への導線

## `/children`

- 親のみアクセス可能
- リンク済みの子ども一覧をカード表示
- 各カードに以下を表示
  - 子どもの名前
  - 円換算レート
  - 今月の合計ポイント
  - 概算金額
  - 未承認ルール件数
- 各カードから以下へ遷移
  - ルール管理
  - ポイント管理

## `/rules/[childId]`

- 月選択
- 月内ルール件数表示
- ルール作成フォーム
  - ラベル
  - ポイント値
- ルール一覧
  - ラベル
  - ポイント値
  - ステータス
  - 作成者
  - 承認履歴
- 承認アクション
  - 子は自分の承認のみ可能
  - 親は親承認または却下が可能

## `/points/[childId]`

- 対象日選択
- 今月サマリー
  - 合計ポイント
  - 円換算額
  - 締め状態
  - 最終更新日時
- アクティブルール一覧
  - タップで記録
- 任意ポイントフォーム
  - メモ
  - ポイント値
- 履歴一覧
  - 日付
  - 内容
  - 増減
  - 登録者
- 月締めボタン
- 締め済み月の親向け編集注意表示
